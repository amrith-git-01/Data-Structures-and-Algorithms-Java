## 📌 Key Concepts by Difficulty


| Difficulty | Core Concepts                                                                       |
| ---------- | ----------------------------------------------------------------------------------- |
| 🟢 Easy    | Character traversal, frequency counting, basic comparisons, two pointers            |
| 🟡 Medium  | Sliding window, substring problems, string simulation, character mapping            |
| 🔴 Hard    | KMP / Rabin-Karp pattern matching, advanced sliding window, palindrome construction |


---

## 🎯 Recommended Practice Order

1. **Valid Palindrome → Reverse String → Anagram Check** — build basics
2. **Longest Common Prefix → Isomorphic Strings** — character mapping
3. **Longest Substring Without Repeating Characters** — sliding window intro
4. **Longest Palindromic Substring** — core medium
5. **Minimum Window Substring** — master sliding window for hard
